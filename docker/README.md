# Deployment configuration

Compose overlays and host configuration for the released single-node team
and standalone baseline. The team base is generated by
[`tools/gen-compose-prod.py`](../tools/gen-compose-prod.py) as ignored
`_gen-prod.<profile>.yml`; [`Makefile`](../Makefile) applies the team overlay.

| Path | Purpose |
|---|---|
| `docker-compose.pbench.yml` | Team network isolation, model egress proxy and MySQL TCP health check |
| `docker-compose.single-agent.yml` | Standalone Copilot worker, proxy, private mounts and subnets |
| [bootstrap/](bootstrap/README.md) | One-shot Gitea/Mattermost account and token provisioning |
| [nginx-edge/](nginx-edge/README.md) | Host-facing HTTP routes for repository and chat services |
| `pbench.slice` | Host cgroup ceiling: 80% memory, no swap and an aggregate task limit |
| `pbench-reboot-guard.service` | Stops all running `omcgitea-*` Compose projects after a host reboot |

The generated team base defines shared services and one worker/router pair
per agent. Bootstrap completes before workers start. Each worker has private
HOME, token and socket mounts; MySQL stores events and board history. The
default network is internal, the model proxy also joins `egress`, and the
edge proxy also joins `edge` for host access.

Team environment comes from `.env.<profile>`. The standalone launcher supplies
its own project, image, path and subnet variables to the standalone Compose
file. Its `/workspace` and `/work` mounts point to the same source tree so
the common archive bridge can save it.

Use `make help` at the repository root for team lifecycle commands.
`make down PROFILE=…` preserves data; `make clean PROFILE=…` deletes that
profile's data. Host guard installation and launch prerequisites are in the
[reproduction guide](../REPRODUCE.md#prerequisites).

The reboot guard assumes matching projects are orphaned after boot; it does
not test driver liveness or restrict matches to this checkout. Use
`PBENCH_GUARD_DRY_RUN=1 bash scripts/pbench_reboot_guard.sh` to inspect its scope
before invoking it manually.
